企業入口網站 (假想宿主頁面)

展示如何將「訂餐系統」作為小工具 (Widget) 嵌入到任何現有的內部系統中。

💡 注意： 下方的內容是透過 <iframe> 從 Astro 開發伺服器（預設為 localhost:4321）跨網域嵌入的。

實作可能性與限制說明：

  • URL 方案： 本 PoC 直接連結開發伺服器。部屬至 Vercel 或 Netlify 後，只需更換 src 為該 URL。
  • X-Frame-Options： 在 astro.config.mjs 或伺服器中，必須確保沒有設定 DENY。如果使用 SSR，需確保 HTTP 標頭允許嵌入。
  • 高度自適應： 由於本應用程式使用了 RWD 佈局，嵌入容器的寬度可以自由調整，內容會自動調適。若要高度也自適應，可使用 PostMessage API 由 iframe 告知父視窗其內容高度。
  • 網域驗證： 建議在生產環境使用 CSP frame-ancestors 來限制哪些網域可以嵌入本程式。
